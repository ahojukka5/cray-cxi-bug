Clean runs: 512 nodes 1 of 3, 640 nodes 0 of 3, 768 nodes 0 of 3,
1024 nodes 0 of 3. Every failure is the same `No route to host` abort
in MPI_Waitall with 2(P-1) requests outstanding.

No Julia, no application code, no compute kernels: MPI over HIP device
buffers and nothing else. The application record matches: 0 of 10
above 512 nodes (Lieb.jl jobs 22223239, 22229860, 22231048, 22233653,
22240542, 22240544, 22240545 at 768 nodes; 22240546, 22240547, 22240548
at 1024), every one on its first Hx, while 384 and 512 nodes produced
clean runs in the same period. The application is not the cause.

The answer is a gradient, not a boundary at 6144 ranks. 512 nodes still
completes some of the time; from 640 nodes upward nothing completed,
and above 512 nodes the failure comes on the first exchange rather than
part way through. Twelve runs in one two-hour evening window cannot
separate rank count from time of day (see failure-rate-vs-time.txt),
so the statement is limited to that window.
